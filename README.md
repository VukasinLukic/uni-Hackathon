# 🛣️ RoadSense Timișoara

Smart real-time pothole detection and repair management system.

## 📦 Project Structure

```
├── mobile/     # React Native iOS App (Vukasin)
├── backend/    # Node.js + Express API (Nemanja)
└── web/        # React Dashboard (Teodora)
```

## 🚀 Quick Start

### Mobile App
```bash
cd mobile
npm install
npm start
```

### Backend
```bash
cd backend
npm install
cp .env.example .env
npm run dev
```

### Web Dashboard
```bash
cd web
npm install
cp .env.example .env
npm run dev
```

- **Mobile**: React Native + Expo + TypeScript
- **Backend**: Node.js + Express + MongoDB
- **Web**: React + Vite + TypeScript + Tailwind
- **AI**: Google Gemini API
- **Auth**: Auth0
- **Maps**: Mapbox
- **Real-time**: Socket.IO
